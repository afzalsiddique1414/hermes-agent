# JARVIS project context

This repository is the user's personal Hermes Agent fork. Follow [JARVIS_OPERATOR_SPEC.md](JARVIS_OPERATOR_SPEC.md) as the project contract.

Priority: build and verify an always-available, phone-first personal operator, beginning with a single-user Telegram MVP, then durable cross-platform task continuity and additional channels. Hermes already contains extensive gateway, memory, voice, scheduler, and delegation features; reuse supported upstream capabilities before adding custom infrastructure.

Work in feature branches and pull requests. Do not claim something works until an end-to-end test proves it. Keep a current checklist of what is implemented, what is tested, and what remains blocked.

Hard boundaries: no Mizan resource changes; paper trading only; CoinSwitch read-only; no live orders; no paid services without explicit approval; no secrets in Git; no bypassing app access controls or licenses; user approval required before external-impact actions.
